# Preet Baldha — Personal Portfolio

Professional, responsive portfolio for **Preet Baldha**, a B.Tech Information Technology student at Atmiya University.

## Included

- Resume download using the supplied resume PDF
- Education and academic details from the resume
- Skills: Java, Python, HTML, CSS, PHP and database concepts
- Projects connected to the current GitHub profile
- Responsive mobile navigation
- Project filtering
- Accessible contact form that opens the visitor's email client
- Lightweight reveal and typing animations with no animation framework dependency
- GitHub profile and repository links

## GitHub

https://github.com/baldhapreet-web

## Run locally

Open `index.html` directly, or use VS Code Live Server.

## Deployment

The site is static and can be deployed to GitHub Pages, Vercel, Netlify or another static host.
